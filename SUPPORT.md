# Support

Use GitHub Discussions for usage questions and design conversations when Discussions are enabled. Use Issues for reproducible bugs and accepted feature proposals.

Before requesting help:

1. Run `npx prompt-sift doctor`.
2. Run `npm run check` if working from source.
3. Remove credentials and proprietary source from logs and examples.
4. Include the operating system, Node.js version, PromptSift version, host surface, and worker type.

Security concerns must follow [SECURITY.md](SECURITY.md).
